# Lanius color concepts

These are visual studies for the Target → Endpoints screen. They use the same
fictional sample data so the colors can be compared directly. The app uses the
listed palette values, while actual typography, saved column widths, and
captured data depend on the user's settings and project.

| File | Direction | Background | Surface | Accent | Selection |
| --- | --- | --- | --- | --- | --- |
| `copper.png` | Charcoal and muted copper | `#1C1E1F` | `#252829` | `#B99063` | `#39332B` |
| `steel.png` | Slate and steel blue | `#1A2024` | `#232B30` | `#84AFC2` | `#293E48` |
| `sage.png` | Deep olive and sage | `#1D211D` | `#272C27` | `#A7B98A` | `#333D31` |
| `paper.png` | Warm paper and deep green | `#F4F4EF` | `#FCFBF8` | `#486D61` | `#DCEAE2` |

`compare.png` places the four previews together. `mockup.html` contains the
palette definitions and layout used to render them.
