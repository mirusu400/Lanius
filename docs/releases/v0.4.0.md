# Lanius 0.4.0

This release makes testing sessions easier to resume and improves desktop reliability across platforms. These changes are relative to [v0.3.0](v0.3.0.md).

## Highlights

- **Resume testing work:** Fuzzer keeps past runs and multiple request drafts. Workspace tabs reopen after exit, and imported project tabs are restored. Project exports and HTTP history searches now show progress.
- **Edit and navigate traffic:** Replay and Fuzzer highlight HTTP request and response content. Request editors share undo history and consistent context menus, including explicit choices for Scope rules. Configurable shortcuts send requests to Replay and Fuzzer. The Intercept queue can be resized and filtered like HTTP History.
- **Manage projects and storage:** Import SQLite project databases, browse large histories more quickly, set limits for stored media bodies, and search settings with highlighted destinations.
- **Improve platform integration:** Upstream TLS uses system certificate roots on Linux and Windows. Windows CA trust checks, macOS network extension guidance, and VMware WebKit startup have been improved. Signed updates work more consistently across channels and installer types.

## Installation notes

The macOS and Windows packages are not signed by Apple or Microsoft. On macOS, after installing the app, run `xattr -dr com.apple.quarantine /Applications/Lanius.app` before the first launch. On Windows, SmartScreen may require **More info** then **Run anyway**. Debian packages use the download link for later upgrades; they do not replace themselves through the in-app updater.

Lanius is for security testing of systems you are authorised to test.
