# Lanius 0.3.0

This release improves the daily workflow for inspecting traffic, diagnosing setup problems, and extending Lanius with plugins. These changes are relative to [v0.2.0](v0.2.0.md).

## Highlights

- **Work through HTTP history:** bookmark and highlight flows, filter by annotations, and use MCP tools to manage bookmarks. History can display the local source IP of captured connections. Filters, selection, and scroll position survive switching workspace tabs; paging and navigation have been improved.
- **Keep every edit:** Intercept preserves drafts and shows the original, automatically modified, and final request versions. Intercepted flows now expose history actions. Replay stores the latest 50 sends per tab, including request and response pairs, and lets you browse them beside the editor.
- **Check your setup:** Dashboard Doctor reports local engine and proxy listener readiness, browser and CA availability, system capture approval, and whether traffic has arrived. Its checks do not contact an external site.
- **Build and inspect plugins:** the SDK supports request-level active scanner checks and targeted runs. Signed catalogue cards can show details and embedded icons, with a more helpful empty state.
- **Connect agents and find help:** Settings offers one-line MCP setup commands for Codex and Claude Code. MCP guidance describes read-only SQLite analysis for large local queries. A new [website and feature wiki](https://lanius.mir.sh/) is also available in the app's Docs tab.

## Fixes

- Clearing a large HTTP history no longer stalls the UI, and the reset flow now confirms the destructive action.
- Updated `source-map-js` to a patched version.

## Installation notes

The macOS and Windows packages are not signed by Apple or Microsoft. On macOS, after installing the app, run `xattr -dr com.apple.quarantine /Applications/Lanius.app` before the first launch. On Windows, SmartScreen may require **More info** then **Run anyway**. Debian packages use the download link for later upgrades; they do not replace themselves through the in-app updater.

Lanius is for security testing of systems you are authorised to test.
