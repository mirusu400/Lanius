# Lanius 0.2.0 — initial stable release

This is Lanius's first stable desktop release. There is no earlier stable version to compare against.

## Highlights

- **Inspect and change traffic:** capture HTTP/HTTPS, HTTP/2, WebSocket, and raw TCP traffic; hold and edit requests in Intercept; send traffic to Replay and Fuzzer; and work with project scope, Target, Decoder, and Diff.
- **Find what matters in history:** search within HTTP request and response details. Matches are highlighted in source views and HTML previews, including the editor changes added for this release.
- **Extend Lanius with plugins:** use the versioned plugin SDK, signed plugin packages and catalogues, actions in the workspace, scanner findings in Issues, and live plugin logs and diagnostics.
- **Work with AI agents:** the local MCP endpoint exposes capture, scope, Intercept, and Replay tools. Agent access can be disabled, and secrets are redacted unless explicitly requested.
- **Control network access:** global and project Lockdown Mode block Lanius-owned outbound requests. Project scope egress can additionally restrict proxy and Replay/Fuzzer connections while Lockdown is active.
- **Update deliberately:** stable and nightly builds have separate update feeds. The desktop updater verifies signed artifacts and installs only after you choose to update.

## Installation notes

The macOS and Windows packages are not signed by Apple or Microsoft. On macOS, after installing the app, run `xattr -dr com.apple.quarantine /Applications/Lanius.app` before the first launch. On Windows, SmartScreen may require **More info** then **Run anyway**. Debian packages use the download link for later upgrades; they do not replace themselves through the in-app updater.

Lanius is for security testing of systems you are authorised to test.
