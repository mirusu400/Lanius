# Lanius 0.7.0

This release pins traffic to a confirmed public IP, makes HTTP History easier to
work through in bulk, and lets plugins render messages in their own tabs.
These changes are relative to [v0.6.0](v0.6.0.md).

## Highlights

- **Pin traffic to a public IP:** **Settings > Observed public IP** adds
  **Only communicate from this public IP**. After confirmation, proxy, Replay,
  Fuzzer, and raw TCP/UDP/DNS traffic leaves only while the observer confirms
  the pinned address. The guard refuses before DNS lookup or socket creation
  and fails closed when a confirmation expires, the observer fails, the address
  changes, or a local interface or upstream route changes. Live connections,
  held Intercept requests, and running Replay and Fuzzer requests are closed as
  soon as the pin stops being confirmed.
- **Act on several History rows at once:** Ctrl/Cmd+click toggles a row,
  Shift+click and Shift+Arrow extend a range, and Ctrl/Cmd+A selects the page.
  The context menu on a multi-selection sends every selected request to Replay,
  bookmarks or highlights them, copies their URLs, or deletes them.
- **Find tool traffic in History:** requests sent from Replay and Fuzzer are
  labelled in a new **Tool** column and can be hidden from **Filter...**. The
  extension filter now offers separate presets for formats you usually inspect
  and static assets you usually hide, and search matches full request URLs,
  including scheme, host, port, path, and query together.
- **Encode and decode in place:** the Replay, Fuzzer, and Intercept editor menus
  can URL, Base64, Base64URL, HTML, or hex encode the selected text and decode
  URL, Base64, HTML, or hex back again.
- **Extend message views with plugins:** Plugin SDK 1.7 adds
  `context.message_views`. Plugin tabs appear beside Pretty, Raw, and Hex in
  HTTP History, Replay, Fuzzer, and Intercept. A view with an `apply` function
  can turn edits back into the raw message where the message is editable.
  Reloading a plugin now re-reads its `plugin.json`.
- **Choose fonts and browser profiles:** interface and editor font fields list
  the fonts installed on this machine, drawn in their own typeface, with
  fixed-width fonts first for the editor. **Settings > Browser** can keep the
  Lanius browser profile in a chosen folder so separate sets of cookies and
  logins can be switched between.
- **Smaller interface fixes:** Replay shows the response time in the response
  header, and toasts can be closed directly and leave the screen sooner.

## Notable behavior changes

- The public IP pin is stored in the project database, so exports carry it. It
  cannot be turned on while Lockdown Mode is active, and a pinned project blocks
  all user traffic while Lockdown Mode is active because the observer cannot
  run. The pin can always be removed, and public IP recording cannot be turned
  off while a project is pinned.
- Opening a project from an earlier version rebuilds its search index once so
  existing captures can be found by full URL. Large projects may take longer to
  open the first time.
- Fuzzer requests recorded before the **Tool** column existed are listed as
  Replay.
- A chosen browser data folder is only adopted when it is empty or already a
  Chromium profile. Lanius clears a chosen folder only after it has launched a
  browser there.
- Toasts close after 2.5 seconds, or 4 seconds for errors, instead of 4.5 and 8
  seconds.
- The SDK version is now 1.7. Plugin packages that use message views should
  declare `"sdk": ">=1.7,<2"`; packages with an open-ended `<2` range continue
  to install.

## Installation notes

The macOS and Windows packages are not signed by Apple or Microsoft. On macOS,
after installing the app, run
`xattr -dr com.apple.quarantine /Applications/Lanius.app` before the first
launch. On Windows, SmartScreen may require **More info** then **Run anyway**.
Debian packages use the download link for later upgrades; they do not replace
themselves through the in-app updater.

Lanius is for security testing of systems you are authorised to test.
