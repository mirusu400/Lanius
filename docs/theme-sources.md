# Theme palette sources

Lanius adapts the key colors of these editor palettes to its own interface.
Additional surfaces, selection colors, and status shades are mapped for
Lanius. These are not official ports, and no theme icons are included.

| Lanius preset | Color reference | Source license |
| --- | --- | --- |
| Monokai Classic | [VS Code's built-in Monokai](https://github.com/microsoft/vscode/blob/main/extensions/theme-monokai/themes/monokai-color-theme.json) | [MIT](https://github.com/microsoft/vscode/blob/main/LICENSE.txt) |
| Gruvbox Dark | [Gruvbox palette](https://github.com/morhetz/gruvbox/blob/master/colors/gruvbox.vim) | [MIT/X11](https://github.com/morhetz/gruvbox#license) |
| Dracula | [Dracula palette](https://github.com/dracula/dracula-theme#color-palette-oss) | [MIT](https://github.com/dracula/dracula-theme#license) |
| Tokyo Night | [Tokyo Night palette](https://github.com/tokyo-night/tokyo-night-vscode-theme#color-palette) | [MIT](https://github.com/tokyo-night/tokyo-night-vscode-theme/blob/master/LICENSE.txt) |
| Catppuccin Mocha | [Catppuccin palette](https://github.com/catppuccin/catppuccin#-palette) | [MIT](https://github.com/catppuccin/catppuccin#-license) |
| Solarized Dark | [Solarized palette](https://github.com/altercation/solarized#the-values) | [MIT](https://github.com/altercation/solarized#license) |

Monokai Classic uses the VS Code open-source palette, not Monokai Pro. The
latter has separate [community edition terms](https://monokai.pro/contribute).
